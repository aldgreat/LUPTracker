♻️ Refund Process

🔒 Attorney-Client Privilege Document

The Recall Refund Playbook is designed to support our Customer Service team by clearly outlining the refund workflow, from intake to validation to completion.

Customer Notification Sources

  • FDA press release (1/14) - Expiration dates 08/2026 to 01/2028 affected.
  • CDC press release / Social Media (1/14).
  • Live It Up customer email outreach (Starting 1/15) - Direct links to Gorgias / Forms.
  • Live It Up website footer & Super Greens PDP blog post (Starting 1/26).

Customer Inquiries & Submissions

Customers submit claims via Refund Request Form A (requires Order # & Lot # Photo) or Form B (missing Order # / Lot #). Manual ticket submissions must be added to the Refund Tracking spreadsheet manually.

✔️ Refund Criteria

Valid Refund Requirements

  • Lot Number starting with “A” or “3”.
  • Valid Email Address & Order Number.
  • Valid Picture: Package photo showing Lot Code/Exp Date OR canister/storage photo.

Refund Terms

  • Applies to current/non-current subscribers and single-time purchasers.
  • Refund covers ONE bag of Super Greens (or unfinished bags from bulk orders).
  • Full refund including shipping and tax (calculated from what was paid at purchase time).

👍 Refund Validation Workflow

  1. Log into the Vibe Refunding Portal, assign yourself, filter by status "New", and sort by Email.
  2. Verify Lot #: Must start with "A" or "3".
  3. Look up Order # in Shopify. Confirm single-unit or multiple-unit purchase.
  4. Validate Photo in Asana.
  5. Set status to Confirmed, Denied, or Follow-up. Never leave a ticket as "New".

🛍️ Replacement Bag Redemption

Applies to requests with Status: Confirmed and Type: Replacement Bag.

  • Unique, one-time discount code per customer email (auto-applied via personalized URL).
  • All bags must be added and redeemed in a single order.
  • Super Greens is on pre-order and expected to ship Summer 2026. All other products ship immediately.

➕ Store Credit Guidelines

Active Subscribers (Recharge)

Credits are added to Recharge accounts. Customers toggle "Auto-apply to next order" in their account portal.

Non-Subscribers (Shopify)

Credits are added to Shopify accounts. Customers sign in at checkout via the purple Shop icon to apply store credit.

💰 Cash Refunds

Cash refunds are processed over a rolling period. Customers receive an automated approval notification letting them know the refund has been scheduled.

🅰️ Amazon Orders Protocol

  • Official Amazon Store: Confirm with team, offer Replacement Bag first. If declined, post details in #amazon-orders-recall Slack channel for manual refund.
  • 3rd Party Resellers: Direct customer to the original seller. If escalated, require invoice + photo proof to process manual PayPal or check refund.

🤖 Portal Automations

  • Auto-Approval: Valid Order # + Unique + <$45 + Approved Lot Code + Created > 2025-01-01 $\rightarrow$ Set to Confirmed.
  • Amazon Filter: Order ID containing "111-", "112-", "113-", "114-", or "Amazon" $\rightarrow$ Set to Denied.
  • Invalid Lot Code: Lot # starting with "P" $\rightarrow$ Set to Denied.
